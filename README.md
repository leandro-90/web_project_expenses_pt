# 📊 TripleTen - Projeto de Controle de Despesas

Uma aplicação web moderna e responsiva voltada para o gerenciamento de finanças pessoais e controle de despesas diárias, desenvolvida com foco em acessibilidade e facilidade de navegação.

🔗 **Acesse o site:** [leandro-90.github.io/web_project_expenses_pt](https://leandro-90.github.io/web_project_expenses_pt/)

---

## 📌 Sobre o Projeto

O **Projeto de Controle de Despesas** é uma página intuitiva e responsiva criada para ajudar usuários a visualizar, organizar e acompanhar seus gastos e orçamentos de forma clara. 

A aplicação foi desenvolvida seguindo padrões modernos de marcação semântica e boas práticas de arquitetura CSS, garantindo uma interface fluida tanto em dispositivos móveis quanto em computadores.

### 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura semântica para melhor acessibilidade (SEO/screen readers).
- **CSS3:** Estilização com **Flexbox** e **CSS Grid**, media queries para responsividade e variáveis CSS para controle de temas e paletas de cores.
- **Metodologia BEM (Block Element Modifier):** Organização modular de classes CSS para manter o código limpo, legível e reusável.
- **JavaScript (ES6+):** Manipulação básica de eventos e dinâmica do layout.

---

## 🎨 Funcionalidades e Destaques

- **Dashboard Visual de Gastos:** Apresentação clara de orçamentos, entradas e saídas financeiras.
- **Layout Responsivo (Mobile-First):** Adaptação perfeita para celulares, tablets e monitores widescreen.
- **Navegação Intuitiva:** Estrutura focada em usabilidade e experiência do usuário (UX).
- **Código Modular:** Estruturação BEM que facilita a manutenção e escalabilidade do projeto.
